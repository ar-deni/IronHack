# Bouncing Ball Animation

This project demonstrates a bouncing ball animation using CSS @keyframes as part of the Ironhack Week 3, Day 4 lab assignment.

## Description

The animation shows a ball bouncing vertically with a squash effect when it hits the ground. The animation uses CSS @keyframes to create a realistic bouncing motion that loops infinitely.

## Files

- `index.html` - Contains the ball element
- `styles.css` - Contains the animation using @keyframes

## How It Works

The animation uses:
- `position: relative` to enable positioning
- `@keyframes` to define the animation sequence
- `transform: scaleY()` to create the squash effect when the ball hits the ground
- `animation: bounce 2s infinite` to apply the animation infinitely

## Implementation Details

The keyframes define the ball's movement:
- Starts at the top
- Falls to the bottom with a squash effect on impact
- Bounces back to the top
- Loops infinitely
